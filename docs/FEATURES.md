# Features Overview

## Authentication
- Users can register, login, and reset passwords securely.
- JWT based authentication with encrypted password handling.

## Property Listings
- Users can create, edit, and delete property listings.
- Supports image uploads (now integrated with AWS S3).
- Property details include location, price, amenities, and description.

## Messaging
- Real-time chat between users interested in a property.
- Message history is stored and displayed in the UI.

## Map Integration & Search
- Interactive map showing property locations with clustering.
- Advanced search filters: price range, pet‑friendly, amenities, proximity, etc.

## UI/UX Enhancements
- Glassmorphism header, dark mode support, responsive design.
- Accessibility improvements and performance optimizations.

## Deployment
- Dockerized application with scripts for local development and production deployment on AWS.
